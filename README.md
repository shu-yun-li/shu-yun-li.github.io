# Shuyun Li — Personal Website

Personal academic and design portfolio for Shuyun Li.

**Live site:** [shu-yun-li.github.io](https://shu-yun-li.github.io/)

## About

This website brings together my work across human–computer interaction, experience design, garments, and textiles. It is designed as a clear, evolving archive for research, selected projects, and professional experience.

## Current sections

- Research interests
- Selected work, including Carewear+
- Education and experience
- CV and project archive placeholders

## Design

The site uses a responsive, information-first layout with a white background, deep green typography, pale mint accents, and subtle sakura-pink highlights.

- Semantic HTML

- GitHub Pages
